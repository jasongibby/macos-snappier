# macOS Snappier

A small set of `defaults` tweaks I use to make macOS feel less sluggish. It turns down window, scrolling, Dock, Finder, and Mail animations, and makes key repeat faster.

Run it with:

```bash
chmod +x snappier-macos.sh
./snappier-macos.sh
```

The script restarts Dock, Finder, and Mail so most changes take effect right away. Log out and back in if a global setting does not stick immediately.

These are personal preferences, not a benchmark. Read the script before running it and change anything you do not want.
